# 🛒 Amazon Clone

A front-end clone of the Amazon.in homepage, built with plain HTML and CSS to practice replicating a complex, real-world e-commerce layout.

## About

This project recreates the Amazon homepage — navbar with search bar and category selector, category menu strip, promotional deal sections with image grids, and a multi-column footer — using only static markup and styling. It's a layout and CSS practice project rather than a functional store, focused on nailing the spacing, grid alignment, and visual hierarchy of a real production site.

## Features

- Sticky navbar with logo, address, search bar with category dropdown, account/orders links, and cart icon
- Horizontal scrollable category menu (Electronics, Fashion, Books, etc.)
- Promotional "deal box" sections with single images and 2x2 image grids
- Multi-column footer with grouped links and a language/region selector
- Font Awesome icons for search, cart, and location

## Built With

- HTML5
- CSS3
- [Font Awesome](https://fontawesome.com/) (via CDN)

## Getting Started

Clone the repo and open `index.html` directly in your browser — no build step or dependencies required.

```bash
git clone https://github.com/<your-username>/AmazonClone.git
cd AmazonClone
open index.html   # or double-click the file
```
